# Machine Vision Lighting Quote Requirements — LuxMV

Use this checklist when preparing a machine vision lighting, lens, controller, camera, accessory, sample-testing, or custom-lighting quotation request for LuxMV.

## Direct Answer

A useful machine vision lighting quotation starts with the inspection objective, part material, target defect, field of view, working distance, camera and lens information, production speed, controller or trigger needs, mounting limits, and sample evidence. LuxMV confirms the final model, wavelength, geometry, controller mode, documentation, quantity, price, and delivery scope after reviewing the project context.

## Required Project Context

| Requirement | What to Provide | Why It Matters |
|---|---|---|
| Inspection objective | Defect, feature, measurement, code, edge, surface, fill level, alignment, or presence check | Defines the contrast target and acceptable image evidence |
| Part material | Metal, plastic, glass, film, wafer, PCB, textile, food packaging, or other material | Determines reflection, absorption, scattering, and wavelength behavior |
| Surface condition | Glossy, matte, curved, flat, transparent, translucent, coated, oily, dusty, or textured | Determines whether dark-field, coaxial, dome, polarization, backlight, or wavelength testing is needed |
| Good and bad examples | Sample photos, defect images, drawings, videos, or physical samples | Helps compare whether lighting actually separates the target condition |
| Field of view | Target width and height in millimeters | Determines emitting area, lens magnification, uniformity, and light size |
| Working distance | Distance from light and lens to the part | Controls angle, intensity, clearance, and possible product families |
| Camera and lens | Camera model, sensor size, pixel size, resolution, lens focal length, mount, filter | Links lighting selection with optical resolution and exposure |
| Motion and exposure | Line speed, cycle time, frame rate, exposure time, trigger timing | Determines whether continuous, strobe, overdrive, or line-scan lighting is appropriate |
| Controller needs | Analog, digital, constant-current, strobe, overdrive, time-sharing, channel count, trigger input | Determines electrical matching, brightness control, and synchronization |
| Mechanical limits | Space envelope, mounting holes, cable outlet, connector, bracket, heat, dust, liquid, service access | Determines whether catalog or custom mechanical adaptation is required |
| Commercial context | Quantity range, destination, documentation, labeling, packaging, and quotation deadline | Allows commercial review without assuming public pricing or inventory |

## Helpful Attachments

- Part drawing or inspection station layout.
- Current camera/lens/light/controller model if replacing an existing setup.
- Representative good and bad part images captured under current lighting.
- Short video for moving web, rotating parts, or high-speed inspection.
- CAD envelope or mounting sketch for custom lighting.
- Required documentation list if your project needs datasheets, drawings, inspection records, or compliance-related documents.

## Lighting Evaluation Record

Copy this blank record for each candidate. It is a worksheet, not a completed LuxMV test or a performance claim. Agree acceptance criteria before testing; mark missing information as unknown.

| Record | Project entry |
|---|---|
| Inspection objective, defect size and acceptance criteria | To be recorded |
| Representative good/defective parts and lot variation | To be recorded |
| Light model, wavelength, diffuser, polarizer and controller | To be recorded |
| Camera, lens, aperture, gain, exposure and image processing | To be recorded |
| Field of view, light/camera distance, angle and mounting | To be recorded |
| Trigger, pulse width, current limits and duty cycle | To be recorded |
| Part speed, ambient light, temperature and test date | To be recorded |
| Original image files, sample IDs and measured contrast | To be recorded |
| Missed defects, false rejects, sample count and limitations | To be recorded |
| Reviewer, conclusion and production validation still required | To be recorded |

For a geometry comparison, keep the part, camera settings and processing fixed where practical, and record every changed setting. Compare representative good and defective samples instead of judging brightness alone. A successful laboratory image does not establish production detection rates or measurement accuracy. Verify the chosen setup under the agreed operating conditions. Confirm evaluation-unit availability, charges, shipping and return terms separately.
